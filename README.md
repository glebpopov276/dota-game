# Сетевая 2D-игра на Python

Кроссплатформенная многопользовательская 2D-игра на Python с хост-архитектурой. Один игрок создаёт игру (хост), второй подключается по IP. Все расчёты выполняются на машине хоста.

## Возможности

- 🎮 Сетевая игра на двух игроков через TCP-сокеты
- 🖥️ Хост-модель: сервер внутри игрового процесса хоста
- ⚔️ Боевая система: стрельба, HP, попадания
- 🏆 Матч до 5 очков, экран победы, рестарт
- 🎨 Спрайты с плавным поворотом по направлению движения
- 📡 Интерполяция движения для плавной картинки
- 🚪 Меню, лобби с вводом IP, лобби хоста с автоопределением адреса

## Технологии

- **Python 3.13**
- **pygame-ce** — графика, ввод, игровой цикл
- **TCP-сокеты** — сетевое взаимодействие
- **threading** — сервер в отдельном потоке
- **JSON** — формат сообщений между хостом и клиентом
- **uv** — управление окружением Python

## Установка и запуск

### Требования

- Python 3.10+
- pip

### Установка

Открой терминал и выполни:

    git clone https://codeberg.org/glebpopov/dota-game.git
    cd dota-game
    python -m venv .venv
    .venv\Scripts\activate
    pip install pygame-ce

Для Linux или macOS последняя команда активации:

    source .venv/bin/activate

### Запуск

Хост — игрок 1:

    python main.py

В меню выбрать «Создать игру (хост)». В лобби появится IP-адрес — сообщить его второму игроку.

Гость — игрок 2:

    python main.py

В меню выбрать «Подключиться (гость)», ввести IP хоста (или 127.0.0.1 для теста на одной машине), нажать Enter.

## Управление

- **W A S D** или **стрелки** — движение
- **Пробел** или **ЛКМ** — стрельба
- **R** (на экране победы) — рестарт матча
- **Esc** (в лобби гостя) — назад в меню

## Как это работает

### Хост-модель

Игра использует авторитетную хост-модель:

- **Хост** держит игровой мир и выполняет все расчёты: движение, стрельба, попадания, счёт.
- **Гость** отправляет только свой ввод (dx, dy, «выстрел») и получает снапшоты состояния для отрисовки.
- Все решения принимаются на хосте — это исключает рассинхрон и читы.

### Сетевой протокол

- **TCP-сокеты** — надёжная доставка сообщений.
- **JSON** — формат обмена. Сообщения разделяются символом переноса строки.
- **Тикрейт сервера** — 30 Hz (33 мс между обновлениями).
- **Рендер клиента** — 60 FPS.

### Сообщения

- `welcome` — хост → гость: при подключении, id игрока
- `state` — хост → гость: снапшот мира (игроки, пули, счёт)
- `input` — гость → хост: ввод dx, dy
- `shoot` — гость → хост: запрос на выстрел
- `reset` — гость → хост: запрос на рестарт матча
- `match_end` — хост → гость: конец матча, id победителя

### Плавность

- **Интерполяция** — гость рисует между двумя последними снапшотами, движение получается плавным.
- **Плавный поворот спрайта** — угол спрайта подтягивается к целевому постепенно, а не мгновенно.
